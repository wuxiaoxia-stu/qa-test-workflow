# Security Policy

## Supported Versions

Security fixes are considered for the latest version on the `main` branch. This project does not promise a support window or backport policy.

## Reporting a Vulnerability

Do not include vulnerability details, exploit steps, tokens, credentials, customer data, or production files in a public issue.

Use GitHub's private security-reporting path for this repository:

<https://github.com/wuxiaoxia-stu/qa-test-workflow/security/advisories/new>

If GitHub does not offer private reporting for the repository, open a minimal public issue titled `Security: request private contact` without technical details. The maintainer can then move the discussion to a private channel.
