# Requirements Analysis Resources

These files support the `requirements-review` mode in `qa-test-workflow`.

- Read `requirements-analysis.md` for the analysis workflow and required six-section report.
- Read `output-formats.md` only when a specific artifact format is requested.
- Use the matching files in `templates/requirements-analysis/` and helpers in `scripts/requirements-analysis/` when conversion is needed.

Install and invoke the package through the repository-root [README](../../README.md). This directory is an internal resource area, not a standalone skill.
